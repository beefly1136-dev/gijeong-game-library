# 기정T의 기술가정 게임센터 게임 파일

게임센터: https://game-center-site.beefly1136.workers.dev/

이 저장소의 main 브랜치가 게임 실행 파일의 원본입니다. 사이트는 게임 전용 서버를 통해 이 저장소의 파일을 읽습니다. 학생의 게임 주소와 저장 기록은 기존 주소를 유지합니다. 파일 변경은 캐시 갱신 후 약 1~2분 후 반영됩니다.

## 기존 게임 수정

아래 표의 게임 폴더를 열고, Add file → Upload files에서 압축을 푼 게임 파일을 올린 후 Commit changes를 누르세요. 실행 파일 이름은 index.html입니다. 이미지·음악 폴더 구조와 파일 이름을 그대로 유지하세요. ZIP 파일 자체는 실행되지 않습니다.

## 새 게임 추가

games/영문게임이름/index.html과 이미지 폴더를 올린 뒤 게임센터의 선생님 관리에서 GitHub 실행 파일 경로를 입력해 등록합니다. 예: games/new-game/index.html. 제목, 단원, 썸네일, 공개 여부는 게임센터에서 관리합니다.
